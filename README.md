\# ASEAN Phonebook



\## Project Description

The ASEAN Phonebook is a C# console application that allows users to store, edit, and search student contact information from five ASEAN countries.



\## Features

\- Store student information.

\- Edit existing student records.

\- Search students by country.

\- Display students alphabetically by surname.

\- Exit the program.



\## Supported Countries

\- Philippines (63)

\- Thailand (66)

\- Singapore (65)

\- Indonesia (62)

\- Malaysia (60)



\## Technologies Used

\- C#

\- .NET

\- Object-Oriented Programming (OOP)

\- Git and GitHub



\## How to Run

1\. Install the .NET SDK.

2\. Download or clone this repository.

3\. Open the project folder in a terminal.

4\. Run the following command:



&#x20;  dotnet run
